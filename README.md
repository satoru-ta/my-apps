# My Apps ホームページ

作ったアプリを紹介するための、シンプルな静的サイトです。HTML/CSS/JSのみで作られており、追加のビルド作業は不要です。

## ファイル構成

```
ホームページ/
├── index.html      # ページ本体
├── css/style.css   # デザイン
├── js/main.js         # アプリ一覧の描画・ダークモード切替
├── js/data-table.js   # Googleスプレッドシート連携のデータ表
└── assets/apps/       # アプリのスクリーンショットなど画像置き場
```

## アプリを追加する方法

`js/main.js` の先頭にある `APPS` 配列に、1個オブジェクトを追加するだけです。

```js
{
  icon: "🚀",          // カード上部に表示する絵文字(画像に差し替え可)
  tag: "ツール",        // フィルターに使うカテゴリ名
  title: "アプリ名",
  desc: "アプリの説明文をここに書きます。",
  demoUrl: "https://...",   // 「試す」ボタンのリンク
  codeUrl: "https://...",   // 「コード」ボタンのリンク(GitHubなど)
}
```

タグは自動でフィルターボタンに反映されます。

## データ表(Googleスプレッドシート連携)

「データ」セクションは、Googleスプレッドシートを公開すると自動で表として表示されます。スプレッドシートを保存するだけで、サイト側は再アップロード不要で最新データを取得します。

### 設定手順

1. Googleスプレッドシートを開き、1行目に見出し(列名)、2行目以降にデータを入力する
2. メニューの「ファイル」→「共有」→「ウェブに公開」を選択
3. 公開する範囲で対象のシートを選び、形式を **カンマ区切りの値(.csv)** にして「公開」をクリック
4. 発行されたURL(`https://docs.google.com/spreadsheets/d/e/2PACX-.../pub?output=csv` のような形式)をコピーする
5. `js/data-table.js` の先頭にある `SHEET_CSV_URL` にそのURLを貼り付ける

```js
const SHEET_CSV_URL = "https://docs.google.com/spreadsheets/d/e/2PACX-xxxxx/pub?output=csv";
```

以降はスプレッドシートを編集・保存するだけで、ページを開いた際に自動で最新データが反映されます(ページの再公開は不要)。

`SHEET_CSV_URL` が空の場合は、動作確認用のサンプルデータが表示されます。

> 注意: 「ウェブに公開」したシートは、URLを知っている人なら誰でも閲覧できます。公開しても問題ないデータのみを載せてください。

## 編集したい主な箇所

- `index.html` の `<h1>` `hero-sub` : キャッチコピー・自己紹介文
- `index.html` の `#about` セクション: 自己紹介・SNSリンク
- `index.html` の `#contact` セクション: 連絡先メールアドレス
- `js/main.js` の `APPS` 配列: アプリ一覧

## ローカルで確認する方法

ブラウザで `index.html` を直接開くだけでも見られますが、正しく表示するには簡易サーバーの利用がおすすめです。

```bash
python -m http.server 8080
```

その後 `http://localhost:8080` を開いてください。

## 公開方法(おすすめ: GitHub Pages)

1. GitHubで新しいリポジトリを作成
2. このフォルダの中身をpush
3. リポジトリの Settings → Pages で公開ブランチを選択

これだけで無料で公開できます。VercelやNetlifyにドラッグ&ドロップでアップロードする方法でも公開可能です。
